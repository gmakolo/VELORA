
# VELORA

### Your Money. Your Future. Your Control.

VELORA is a simulated digital banking web application built with Go. It allows users to create accounts, sign in, and view their banking dashboard.

## Features

- User registration and login
- Secure password hashing
- Automatic account number generation
- User dashboard
- Session management
- SQLite database integration

## Technologies

- Go
- HTML
- CSS
- SQLite
- Gorilla Sessions
- bcrypt


Run the application:
go run .

Open http://localhost:8080 in your browser.
